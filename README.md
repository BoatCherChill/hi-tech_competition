# 🚁 Микроячейка сборки FPV-БВС

**Программно-аппаратный комплекс для автоматизированной сборки, контроля затяжки и маркировки FPV-БВС.**

Проект представляет собой рабочее место оператора (микроячейку), объединяющее в себе программное обеспечение на C++ (Qt) и аппаратную часть на базе Arduino Mega 2560. Комплекс позволяет вести пошаговую сборку, контролировать момент затяжки винтов, автоматически генерировать DataMatrix-маркировку и вести локальную базу данных собранных изделий.

## ✨ Основные возможности

- 📋 **Пошаговая инструкция**: Чтение файлов `.txt` с координатами, скоростью и указаниями для оператора.
- 🔧 **Контроль затяжки**: Чтение тока с датчика для предотвращения срыва резьбы.
- 🖨️ **Маркировка**: Автоматическая генерация DataMatrix (через Python), печать и наклейка этикетки.
- 🗄️ **Локальная БД**: Хранение истории сборок в SQLite (работает без интернета).
- 📊 **Экспорт данных**: Выгрузка базы данных в `.csv` (Excel).
- 🚨 **Безопасность**: Обработка аварийных остановок, концевиков и потери связи с Arduino.
- 🔄 **Восстановление**: Возможность продолжить незавершенную сборку с того же шага.

## 🚀 Инструкция по запуску (для пользователя)

1. Распакуйте папку `Hi-Tech_Release` (она должна содержать `hi-tech.exe`, `_runtime/` и папку `instructions/`).
2. Подключите Arduino Mega 2560 к ПК по USB.
3. Запустите `hi-tech.exe`.
4. Нажмите **«Авто-поиск и подключение»** (программа сама найдет COM-порт).
5. Выберите модель БПЛА и размер, введите ФИО оператора.
6. Нажмите **«НАЧАТЬ РАБОТУ»**.

## 📝 Формат инструкции
Файл инструкции — текстовый файл в кодировке UTF-8. Первая строка — общее количество шагов. Пример:
```text
42
1. auto *Начало* 0 0 0 100 (отправляемся до концевиков)
2. manual *Зафиксируйте раму*
3. auto *Перемещение* 10 10 10 100 (метизы)
4. auto *Перемещение* 15 15 15 50 (отверствие)
5. auto *Затяжка*
...
41. auto *Маркировка*
42. auto *Конец*

**Разбор строки:**
- **`1.`** — номер шага (целое число).
- **`auto` / `manual`** — тип выполнения:
  - `auto` — программа сама отправит команду на Arduino (для `Перемещение`, `Затяжка`, `Маркировка`).
  - `manual` — оператор выполняет действие вручную (например, «Зафиксируйте раму») и нажимает «Далее».
- **`*Название*`** — текст, который видит оператор на экране. Обязательно обрамляется звездочками `*`.
- **`X Y Z`** — координаты в миллиметрах (только для шагов `Перемещение`).
- **`Скорость`** — целое число (только для `Перемещение`). Если не указано, используется 100.
- **`(Примечание)`** — текст в скобках. **Не выводится на экран**, предназначен только для составителя инструкции (например, «отверствие» или «метизы»).

**Важно:**
- Все названия шагов (`Начало`, `Перемещение`, `Затяжка`, `Маркировка`, `Конец`) пишутся **строчными буквами** или с заглавной — парсер не чувствителен к регистру, но ищет ключевые слова.
- Пробелы между элементами строки — обязательны.
- Файл должен быть сохранен в кодировке **UTF-8 без BOM**.

## 🤖 Обработка аварийных ситуаций

| Ситуация | Действие программы |
|---|---|
| Нажата кнопка STOP на Arduino | Остановка моторов, окно «Сохранить результат?» → статус `Сборка прервана` |
| Сработал концевик (X, Y, Z) | Логирование в `log.txt`, работа продолжается (не авария) |
| Потеря связи с Arduino (выдернут USB) | Остановка, окно «Сохранить результат?», выход из программы |
| Срыв затяжки (ток > 0.5 А) | Красная индикация «❌ Не успешно», окно «Сохранить результат?» |
| Закрытие окна (крестик) | Вопрос «Сохранить текущий прогресс?» → статус `Сборка прервана` |

## 🧪 Как проверить работу

1. **Запустите программу**: `hi-tech.exe`. Откроется стартовое окно.
2. **Подключите Arduino**: нажмите «Авто-поиск». В логе появится «Mega успешно подключена».
3. **Выберите модель**: `Model_A`, размер `5-inch`. Программа подтянет инструкцию и сгенерирует SN (например, `Model_A5-001`).
4. **Нажмите «Начать работу»**: переключитесь на рабочий экран.
5. **Пройдите несколько шагов**: нажимайте «Следующая». На шагах `Перемещение` будет отправлена команда `MOVE`, координаты обновятся.
6. **Дойдите до шага «Затяжка»**: нажмите «Начать затяжку». Светодиод станет желтым, затем (при успехе) — зеленым и появится «✅ Успешно».
7. **Дойдите до шага «Маркировка»**: нажмите «Наклеить маркировку». Сгенерируется DataMatrix, откроется окно с печатью.
8. **Завершите сборку**: выберите статус «Собран». В логе будет «Запись добавлена в БД (Статус: Собран). Время записи: X мс».
9. **Проверьте БД**: нажмите «📁 Просмотр базы данных» — запись должна быть в таблице.
10. **Проверьте логи**: откройте `logs/log.txt` — все шаги и события должны быть записаны.
